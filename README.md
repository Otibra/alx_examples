# Python Mini Project

## Simple Calculator & Login System

### Overview

This is a beginner Python project that demonstrates the use of **functions, classes, if statements, and for loops**.
The project includes a **simple calculator** and a **basic user login system**.

### Features

* User login authentication
* Basic calculator operations (+, -, *, /)
* Use of Python **functions and classes**
* Command-line interaction

### Concepts Used

* **Functions** – organize and reuse code
* **Classes** – structure user login logic
* **If statements** – handle conditions (login validation, calculator operations)
* **For loops** – iterate through data when needed

### Run the Project

```bash
python main.py
```
